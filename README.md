# Gravitational_Field
This code is written for the calculation of gravitational potential in aspherical bodies using the particle relabelling transformation method. Documentation (still being finalised) is available here: https://adcm2.github.io/SpecRelab/gplspec/.

Current documentation: [GPLSpec guides](https://adcm2.github.io/SpecRelab/gplspec/). The legacy GPLSpec Pages address remains a compatibility entry point.
