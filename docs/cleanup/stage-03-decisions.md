# Stage 03 utility decisions

| Category | Consolidation | Contract and deliberate boundary |
|---|---|---|
| Harmonic indexing | Replaced seven active copies of the triangular non-negative-order coefficient formula with `GPLSpec::detail::NonNegativeHarmonicIndex`; removed one dead local reference after its only use was confirmed commented out. | The helper maps signed `m` to the existing non-negative coefficient slot for `|m|`, preserving the original integer expression and `int` result. Full signed-`m` indexing such as `l*l + l + m` remains distinct. |
| Full/reduced scalar conversion | Replaced six repeated real-field expansion loops in three constructors and three output paths with `ExpandRealScalarCoefficients`. | Preserves degree order, negative-then-nonnegative `m` slot order, `pow(-1.0, m) * conj(c_l,|m|)` phase/conjugation, vector extents, and double-complex storage. No batching or coefficient-layout change. |
| Radial interval/node mapping | Centralized the affine reference-to-physical map. `Radial_Tools::StandardIntervalMap` and `GravityFunctions::StandardIntervalMap` remain as forwarding compatibility wrappers. Replaced repeated physical-radius lambdas and the repeated normalized radial-node map with `StandardIntervalMap` and `ScaledRadialNodeMap`. | The affine helper supports mixed argument types and preserves the expression's natural arithmetic promotions; templated solvers historically passed a `double` reference coordinate with potentially `float` edge nodes. `ScaledRadialNodeMap` explicitly consumes `inner_radius / outer_radius` and returns the existing dimensionless `r/R` map. `GravityFunctions::ScaledIntervalMap`, element-specific `rscale` formulas with different units, and full signed-harmonic indexing are not aliases and remain untouched. |
| Repeated normalization | Replaced the four identical rotation factor expressions with `RotationHarmonicNormalization`. | Retains the exact `3.1415926535` literal, integer denominator expression, and square-root operation. Physical unit factors and model normalization products remain at their call sites. |
| Radial differentiation matrix | Replaced six identical Gauss-point derivative-matrix loops (four `Density3D` construction paths, `General3D`, and `spherical_1D`) with `GaussDerivativeMatrix`. | Accepts the existing polynomial order, uses the same Lagrange polynomial, loop bounds, quadrature evaluation order, dynamic Eigen matrix type, and coefficient layout. Spectral-element weak-form matrices that multiply derivatives and apply interval scaling are distinct and remain unchanged. |

## Focused equivalence checks

`tests/stage03_utilities.cpp` contains copied pre-extraction expressions/loops, independent from the helper calls. It checks all signed orders for degrees 0–12; full scalar expansion for the same degrees; the rotation factor exactly; GLL derivative matrices for supported node counts 3–9; physical interval endpoints/interior points for both compatibility wrappers; mixed `float` edges with a `double` coordinate; and normalized radial mappings at endpoints/interior nodes over several inner/outer ratios. Checks remain active in Release builds.

The tests verify exact equality; stage-00 frozen checks retain `rtol=1e-13`, `atol=1e-15`. No golden output was regenerated.
