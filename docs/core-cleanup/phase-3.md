### Stage 3C.1 source/discretization contract

Use the model-owned `Radial_Tools::RadialMesh` as the sole element geometry and local-sample owner. Its canonical flattened radial degree of freedom is `d(e,j)=e*p+j`, where `p=q.N()-1`, with `E*p+1` total degrees of freedom. Adjacent element endpoints therefore map to the same global radial slot, while each element keeps its own one-sided density sample. A full source vector has `(E*p+1)*(lMax+1)^2` complex entries, ordered by radial degree of freedom then scalar harmonic index `l*l+l+m`.

For an element with physical radii `r0,r1`, quadrature coordinate `xi_j`, and weight `q.W(j)`, compute `r_j=(r0+r1)/2 + (r1-r0)*xi_j/2` and radial measure `w_j=q.W(j)*(r1-r0)/2*r_j^2`. Preserve the existing normalization and source prefactor `4*pi*G`; do not apply an additional density norm. Preserve the current 1-D decimal `pi` literal and 3-D full-precision literal at this checkpoint.

The 1-D spherical rule writes only `l=0,m=0`, with `rho_00=sqrt(4*pi)*rho`, accumulating `4*pi*G*w_j*rho_00` at `d(e,j)`. The 3-D mapped rule transforms each element-local spatial density sample to scalar harmonics, expands real-field negative orders using `rho(l,-m)=(-1)^m conjugate(rho(l,m))`, and accumulates `4*pi*G*w_j*rho_lm` at the same canonical radial degree of freedom. Pinned GSHTrans forward transforms accumulate into the caller-provided output buffer; any reused coefficient workspace must be cleared before each independent transform, matching the prior freshly-zeroed buffer behavior. Preserve the current zero source slots for origin `l>0` and for `m=±lMax` at every radial slot. Keep the 1-D and 3-D source functions explicit because their angular mathematics differs.

The production design adds only global radial indexing/count operations to the already-owned `RadialMesh`, exposes the 1-D model's existing mesh by const reference, and rewrites `FindForce` as direct mathematical loops over element and local sample. It removes the 1-D all-harmonic loop whose only nonzero case is `l=0,m=0`, repeated powers for indexing, copied geometry lists, and duplicated radial-index arithmetic. The operator, preconditioner, solver, boundary-perturbation source, and transform backend are outside this checkpoint.

Focused checks will cover global endpoint sharing and total size; direct low-degree independent angular/radial quadrature for 3-D `l=0,1,2`; a 1-D monopole integral; layered material-interface accumulation with distinct one-sided density values; and the frozen Stage 00/Stage 05 source records. Apply the fixed physical comparison criteria above to numerical values; exact equality is required for the layout map and zero slots.

## Predeclared scientific comparison criteria

Compare physically meaningful values after converting normalized outputs with the documented model scales. For a scalar quantity `q`, use `|q_new-q_ref| <= atol_q + rtol_q*|q_ref|`. For a field, use the physical-unit weighted RMS criterion `RMS_w(q_new-q_ref) <= atol_q + rtol_q*RMS_w(q_ref)`, where `RMS_w(x)=sqrt(sum_i(w_i*|x_i|^2)/sum_i(w_i))`; use the workflow's radial/angular quadrature weights including the physical Jacobian. Report maximum absolute difference as a diagnostic, not a second acceptance gate. Define the absolute term from the physical scale below so values near zero are judged sensibly. Do not use component mismatch counts as an acceptance criterion by themselves.

| Quantity | Comparison criterion fixed before replacement results |
|---|---|
| Parsed input values, integer indices, material boundaries, and exact workflow parameters | Exact equality when the same source text/settings are parsed; reject malformed or non-finite data. |
| Radius/geometry and density samples | `rtol=1e-12`; `atol=1e-14*S_q`, where `S_q` is the model's physical outer radius or reference density scale, respectively. |
| Analytic identities and independently evaluated source/integral quantities | `rtol=1e-11`; `atol=1e-13*S_q`, with `S_q` the corresponding physical analytic/source/integral scale. State quadrature order and convergence evidence alongside the comparison. |
| Potential and gravity fields from solver/workflow comparisons | `rtol=1e-8`; `atol=1e-12*S_q`, where `S_q=max(G*M/R, RMS(|q_ref|))` in physical units for potential, and `S_q=max(G*M/R^2, RMS(|q_ref|))` for acceleration. Report weighted RMS and maximum absolute difference in physical units. |
| Performance | Matched Release build, inputs, thread settings, and repeated substantial runs. Report distributions and memory/iteration/residual evidence; investigate repeatable material regressions, with no threshold inferred from the old sub-millisecond timings. |

The field tolerance is a predeclared regression-comparison criterion, not a claim that the solver's residual alone bounds solution error. Its `1e-8` relative level is looser than the accepted workflow residual observations while remaining small compared with physical field scales; independent analytical checks and mesh/order convergence provide the scientific error evidence. The `1e-12*S_q` absolute floor keeps near-zero components from creating meaningless relative-error failures. These criteria are fixed for the campaign; revise them only if an independent scientific derivation shows the scale is inappropriate, and document that before judging a replacement. The `1e-11` analytic/source criterion applies to exact identities or separately integrated operation checks at stated quadrature order, not a discretized solver versus a continuum solution.

## Current scientific contract to preserve

- **Equation and fields.** Solve the existing Poisson problem `∇²Φ = 4πGρ` through a matrix-free discrete operator `A u = f`. Preserve the existing 1-D and 3-D assembly separately: the 1-D source integrates only the spherical `l=0` density; the 3-D source transforms each radial-node density field and integrates all supported harmonics with radial Gauss weights, the radial Jacobian, `r²`, and `4πG`. Do not infer Hermiticity from those equations: the original dense 1-D complex sesquilinear probe has real and imaginary component defects of about `0.0375` each (complex defect magnitude about `0.0530`), and the 3-D file perturbation probe differs by about `3.56e-8`. These values remain frozen. A focused Sol probe found that zeroing only the unsupported `+lMax` slot makes the 1-D and mapped 3-D base sesquilinear defects zero at printed precision, and the `+lMax` slot is invariant under every probed operator action. Masking both endpoint slots is not invariant: the mapped 3-D base generates the `-lMax` slot with 0.227% of action norm, and the 3-D `NoBoundary()` perturbation action generates endpoint output with 2.55% of action norm when both endpoints are zero in the input. Masking only origin `l>0` is also not invariant; the 1-D action generates those slots at 4.74e-6 of action norm. The original Hermitian-reference difference is explained by testing dense vectors that populate the unsupported `+lMax` slot, but these probes do not justify a blanket Hermitian assumption or an endpoint/origin-reduced operator. Preserve the ambient complex action, the 3-D RHS's current zeroing of both endpoint slots, and the nonzero output slots produced by operator action.
- **Units.** Model radii, density, gravity, potential, and mappings use the constructor's model scales (`LengthNorm`, `MassNorm`, `TimeNorm`, and derived scales). Source assembly consumes the model's stored density and `GravitationalConstant`; it does not apply a second `DensityNorm` factor. Preserve the physical meaning, units, and coordinate conventions at API/output migration points; serialization formats and file names may change.
- **Geometry and mapping.** The radial model supplies material-layer radii and numerical radial elements. A mapping perturbs the reference radial coordinate as supplied by the mapping model; the geometry stores the resulting Jacobian and inverse deformation data and the operator contracts those tensors with canonical spin components. Keep spherical and mapped 1-D/3-D rules explicit.
- **Elements and interfaces.** Each material layer may contain multiple numerical elements. Element-local samples include both endpoints, while the flattened solver vector shares an element endpoint as the next element's start: radial slot `node + polynomial_order*element`, with total radial unknown count `elements*polynomial_order + 1`. Density and geometry retain the element-side sample at a material interface, including one-sided density values. Source assembly accumulates both adjacent element contributions at the shared global unknown. Do not replace material boundaries with numerical-element boundaries or average the one-sided values.
- **Harmonics and grid.** GPLSpec's full scalar solver layout is `l*l + l + m` for `-l ≤ m ≤ l`; GSHTrans's nonnegative-order layout is triangular, and its spin-`n` layout begins at `l=|n|`. For real scalar fields, negative orders use `c(l,-m)=(-1)^m conjugate(c(l,m))`. Pinned GSHTrans `GaussLegendreGrid(lMax,2)` uses `lMax+1` Gauss-Legendre colatitudes and `2*lMax` equally spaced longitudes. Keep spin 0 and spin ±1 components explicit. The origin has zero `l>0` source slots, and current 3-D RHS assembly zeros both `m=±lMax` endpoint slots. The operator preserves the `+lMax` zero slot in the bounded 1-D/3-D probes, but it does not preserve a mask that also excludes `-lMax` or origin `l>0`. The mapped 3-D base and `NoBoundary()` perturbation actions generate excluded-by-RHS endpoint output at 0.227% and 2.55% of action norm, respectively. Treat those slots as part of the ambient operator/result layout; do not impose a false two-endpoint or origin-reduced domain. Raw probe source/results and hashes are retained with Phase 3A evidence in `evidence/phase3a/hermitian-slot-audit.md`, `hermitian-slot-probe.cpp`, and `hermitian-slot-probe.csv`.
- **Boundary and solve.** Preserve the current origin RHS convention (zero source `l>0` slots) while retaining operator-produced origin coefficients in the ambient result, the current outer-radius boundary contribution (operators include it by default and expose `NoBoundary()` for perturbation actions), the complex-vector action, and callers' tolerances. Current 1-D solve uses Eigen BiCGSTAB with the spherical geometry preconditioner. Current 3-D solve uses Eigen ConjugateGradient with the same preconditioner and an initial preconditioner solve. Preserve these algorithms, caller-specific settings, and scientific outputs while simplifying result ownership and representation. Current 3-D diagnostics print iteration count and requested tolerance; independent residuals are not consistently exposed.
- **Exact outer boundary term.** At the final element's final radial node, both wrappers subtract `(l+1) * R_out * u[l,m]` independently for every degree/order, with `R_out` the stored model outer radius. The term is enabled by default and `NoBoundary()` disables it. Preserve its sign, radius scale, and endpoint placement.
- **Source density and scales.** The mapped homogeneous constructors store `J * rho_physical` at each referential sample (`_vec_j` times physical density); this mass-preserving referential density is consumed by the source integral. PREM/tomography constructors start from the input model's radial density and apply the tomography fractional variation directly, without multiplying by a mapping Jacobian. The 3-D source multiplies the transformed density coefficient by `4*pi*G`, `q.W * (Delta r/2)^3 * rscale^2`, where `rscale = xi + (r_upper+r_lower)/Delta r`; this is the reference-coordinate radial volume factor. Do not add another `DensityNorm` factor. Constructor scales are `rho_norm=M_norm/L_norm^3`, `G_model=G_SI*M_norm*T_norm^2/L_norm^3`, and `PotentialNorm=(L_norm/T_norm)^2`.
