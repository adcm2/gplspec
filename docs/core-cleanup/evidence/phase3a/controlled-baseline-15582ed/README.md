# Controlled Phase 3A baseline measurements

This is a five-process-per-fixture timing and memory capture against clean detached baseline `15582edab8112dbb63e0101be5b26f5135298644`. The harness was built in Release from the 3A.2.1 checkout `e0b08ca22484673589b97329ac211afec456ef71`; the runner verified that `gplspec/` and the two benchmark fixture sources have no tracked diff from the baseline. The harness is test-only. It ran with `OMP_NUM_THREADS=1`, `OMP_DYNAMIC=FALSE`, `OPENBLAS_NUM_THREADS=1`, and `MKL_NUM_THREADS=1`.

The mapped fixture reproduces `clean_bench_3`: homogeneous radius/density 1, Earth model scales, `h=0.2`, `npoly=5`, `lmax=2`, maximum radial step `0.1`, ball radius `1.4`, tolerance `1e-12`. The file-backed fixture reproduces `clean_bench_6`: `modeldata/prem.200` and `modeldata/S40RTS_dvs.nc`, `npoly=12`, `lmax=20`, maximum radial step `0.05`, ball radius `1.2`, tolerance `1e-14`. The manifest records both input SHA-256 values and exact raw-file hashes.

The runner uses 0.25-second minimum batches for setup, source assembly, repeated operator action, preconditioner-matrix assembly, solver lifecycle, and end-to-end solve. The single first-action sample is deliberately reported as a cold first call rather than batched. `solver_setup_seconds` is metric-dependent: for `solver_lifecycle` it is Eigen compute and preconditioner installation only; for `end_to_end_solve` it includes all pre-guess work (model, operator, source/RHS, preconditioner matrix, and Eigen solver setup). Solver lifecycle includes the initial guess and iterative solve; it excludes model construction, operator construction, and RHS assembly. End-to-end includes model construction, operator, source, preconditioner matrix, setup, guess, and solve; the independent residual calculation follows the timed solve interval. Every subprocess has a separate peak-RSS measurement.

Across the five processes, mapped median per-call times were 1.76 ms for model construction, 0.383 ms for source assembly, 1.81 ms for repeated operator action, 0.179 ms for preconditioner-matrix assembly, 37.4 ms for solver lifecycle, and 30.1 ms for end-to-end solve. Peak RSS ranged 16,804–17,540 KiB. File-backed medians were 403 ms for model construction, 16.3 ms for source assembly, 75.3 ms for repeated operator action, 201 ms for preconditioner-matrix assembly, 474 ms for solver lifecycle, and 983 ms for end-to-end solve. Peak RSS ranged 572,860–574,432 KiB. These are same-host observations, not performance thresholds; consult the raw per-process CSVs before comparing individual components.

All ten processes exited 3 because the independently recomputed residual exceeded the caller's unchanged tolerance. The mapped solver reported 13 iterations and Eigen error `4.945053761e-13`, while the independent relative residual was `2.079844310e-12` at requested `1e-12`. The file-backed solver displayed 0 iterations and recursive error near `4.47e-21`, while the independent relative residual was `5.484400430e-10` at requested `1e-14`. Every solve row has `independent_gate_pass=0`; `manifest.json` records `scientific_gate_pass=false`. These measurements are baseline evidence only and do not establish solver accuracy or authorize a tolerance/algorithm change.
