Scratch-only attribution recipe (baseline source commit 15582edab8112dbb63e0101be5b26f5135298644):

1. Copy baseline/gplspec to a fresh scratch include root.
2. Apply grid-accessor.patch to the scratch copy only.
3. Compile classical-solver-probe.cpp with BASELINE_PROBE and the baseline build's pinned dependency include roots; use -O3 -DNDEBUG -std=gnu++23 -fopenmp, then link libfftw3, libfftw3f, libfftw3l, and netcdf.
4. Run with OMP_NUM_THREADS=1. gridref.log is the resulting stdout. The probe source in the repository writes a CSV to /tmp; its large CSV is intentionally not archived.

Compiler: GNU C++ 13.3.0. This demonstrates the temporary borrowed-view failure in the tested compiler/build; it is not a claim about every C++ standard-library implementation.
